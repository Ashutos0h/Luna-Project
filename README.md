# 🌙 Luna — Desktop AI Assistant

Luna is a desktop AI assistant built with React, Electron, Vite, and Ollama.

## ✨ Features

- 🤖 Local AI chat using Ollama
- 💬 Persistent conversations
- 🧠 Memory functionality
- 📄 PDF/TXT document Q&A
- ⚙️ Persistent settings
- 🖥️ Desktop application launching
- 🌐 Google/browser search
- 🔒 Privacy and conversation management
- 📦 Windows desktop application

## 🛠️ Tech Stack

- React
- Electron
- Vite
- JavaScript
- Ollama
- Electron IPC
- PDF.js
- Electron Builder

## 🚀 Getting Started

Install dependencies:

```bash
npm install

Start the application:
npm run dev
